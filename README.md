# Kubectl Plugins

A collection of kubectl plugins.

## ctx

Interactively select a context to use.

**Requirements**

`bash` `kubectl` `gum`

**Installation**

```bash
curl -o ~/.local/bin/kubectl-ctx https://codeberg.org/cayne/kubectl-plugins/raw/branch/main/kubectl-ctx
chmod +x ~/.local/bin/kubectl-ctx
```

**Usage**

```bash
kubectl ctx
```
